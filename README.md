# 📚 Atividades e Exercícios - UNIFESP

Repositório dedicado às atividades, exercícios e práticas desenvolvidas durante minha graduação na UNIFESP.

## 🎓 Sobre

Este repositório reúne códigos, listas de exercícios e implementações feitas ao longo das disciplinas do curso. O objetivo é:

- Praticar lógica de programação  
- Consolidar conceitos teóricos  
- Acompanhar minha evolução como desenvolvedor  

## 🧠 Conteúdos

Aqui você vai encontrar exercícios relacionados a:

- Estruturas básicas (variáveis, operadores)
- Condicionais (`if`, `else`)
- Estruturas de repetição (`while`)
- Lógica de programação
- Matemática aplicada à computação
- Outros conteúdos conforme o avanço do curso

## 💻 Linguagens utilizadas

- C (principal)

## 📂 Organização

Os arquivos estão organizados por:

- Disciplina  
- Lista de exercícios  
- Tema específico  

Exemplo:

    /exercicios
        nome_exc.c
    /lista01
        exc01.c
        exc02.c
    /lista02
        exc01.c

## 🚀 Objetivo do repositório

Este repositório serve como:

- Histórico acadêmico  
- Material de revisão  
- Portfólio inicial de programação  

## 📌 Observações

- Os códigos podem conter soluções simples ou em desenvolvimento  
- Alguns exercícios seguem exatamente o enunciado proposto em aula  
- Melhorias e otimizações podem ser feitas com o tempo
